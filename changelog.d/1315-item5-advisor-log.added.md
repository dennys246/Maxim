- **The observer's proposal and refusal log, `maxim.advisor.log`** (#1315 item 5; Experimental): an append-only JSON-lines file, `advisor_log_<session_id>.jsonl`, written through the report directory's fd. Each record is fsynced before `append()` returns (`F_FULLFSYNC` on macOS), and any write or fsync error marks the log broken. `read_log()` drops only a torn final line. Item 1's `maxim.advisor.open()` will be its caller.
