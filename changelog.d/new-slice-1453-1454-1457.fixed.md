- **Typing a new goal after a simulation now continues the run you had** (#1453, #1454, #1457).
  - The new run keeps the settings of the one before it: the sandbox backend, image and network, the AUT's model and
    mode, the turn limits, telemetry, the entity and the arc. Before, a `--sandbox tmpdir` run re-entered with `auto`,
    which picks Docker when the daemon is reachable. A campaign's own inputs do not carry. Every parameter is
    classified, so a new one cannot be dropped by forgetting it.
  - The agent under test starts from the previous run's saved state, so the prompt's "(memory carries over)" is back and
    true. The report's provenance stamps the carry as `resume` with `via: "/new"`.
  - `--report-json` describes the run whose result the caller gets. It used to hold the first run's report.
