## Claim under test

The substrate (NAc `cluster_reward_bias`, substrate-primary `recommend_action` — **no
LLM in the action path**) learns a real-hardware closed-loop sensorimotor policy:
orient a Reachy Mini toward a speech source using the onboard XVF3800 DoA, credited
only by `potential_diff` relief (|az| reduction on re-measured live DoA, Phase 0b).

**Rigor bar (learned ≠ servo):** a hard-coded servo is 100% correct from trial 1.
Three pre-registered separations (harness docstrings, written before the runs):
1. **Learning curve** — frozen-policy probe (argmax per az-bin, no motion, no epsilon)
   starts at 0 on an empty NAc and converges within the session.
2. **Cross-session transfer** — a second session loading the persisted NAc probes
   correct at trial 0, before any experience.
3. **Merge (fleet mechanics)** — two independently-trained NAcs `nac_merge` into a
   policy at least as correct as either input (Hivemind Follow-up A; the probe is
   Queen-tier promotion gauntlet #1).

**Contamination guard:** trials are generated by an apparatus (`--perturb`: commanded
base offsets from a fixed source; balanced bin schedule; two-sided sign self-check
before any learning). Ground truth, gain estimates, and the apparatus servo never
reach NAc — learner state is DoA-derived `az_bin`, credit is re-measured DoA. Apparatus
motion logs as `apparatus_*` events, learner motion as `trial` events.

## Setup

Reachy Mini Wireless (daemon 1.8.3, station mode 10.6.0.63), SDK 1.8.3 (WS transport),
run env `~/Envs/maxim-env`. Sustained speech source (podcast) ~1-2 m, front hemisphere,
fixed during runs. Actions: body YAML `orient` affordances (`turn_left`/`turn_right`)
dispatched as ±0.25 rad **body-yaw** steps (head clamps ±15-18°; body yaw rotates the
head+mic assembly). State: `az_bin` ∈ {center, near/far × left/right}, band 0.1.
Credit: `update_cluster_reward(agent, bin, tool, |az_before|−|az_after|)`. Selection:
epsilon-greedy (ε=0.25) over `recommend_action` (ARGMAX sentinel). NAc checkpointed every
5 trials (`~/.maxim/orient_live/nac_reachy.json`, `_format_version` 1.2).

## Method lineage (what it took to get a clean run — findings, not failures)

1. **Step 2 (2026-07-15, PASSED):** sign calibration — 16/16 valid trials, default
   convention confirmed, body-yaw chosen as orient axis. All trials landed one-sided
   (operator source placement) → motivated the perturb apparatus.
2. **s1 (2026-07-16, forensic):** learning visible (probe 0.75 by trial 20) but three
   byte-identical anti-physical trials at the +1.40 clamp poisoned `near_right`;
   `far_left` never visited; sign-check big rotations read ~0.
3. **Baseline DoA sweep (2026-07-16):** ±1.4 rad, 0.1 increments, both directions.
   **Central finding: the XVF3800 DoA is a tracking estimator** — near-linear under
   small incremental motion (tracked gain **0.58/rad**, ~1° quantization, geometric =
   0.64) but loses lock on large jumps (1.4 rad jump → pinned near stale estimate for
   a half-sweep; hysteresis 0.63 worst-pose). Plus an **endfire bimodal zone** (~90°
   off array axis: samples flip ~+0.28 ↔ ~+0.72) = s1's poison zone. Full data:
   `/tmp/doa_sweep.jsonl` label=baseline.
4. **Apparatus fixes:** all rig moves walked in ≤0.3 rad tracked increments;
   placement targets capped |az| ≤ 0.65; gain prior 0.58. (Generalized into the
   [porting doc](../embodiment/porting_orient_loop.md) as the memoryless-vs-tracker
   calibration step.)

## Results

### Arm 1 — learning curve (s1b, 40 trials, fresh NAc): **PASS**

Sign self-check measured both sides correctly (+0.45→+0.27, −0.45→−0.59). Probe
correctness trajectory: **0.00 (trial 0) → 0.75 (5) → 1.00 (10) → held 1.00 through
40**. (0.00 is "abstains", not chance: an empty/negative-only bin returns no
positive-scored action, which the probe counts incorrect; the executed-action chance
baseline is 0.50 — exactly where m1's greedy rate started.) Every intended bin landed (balanced schedule incl. far_left, the s1 gap).
Greedy turned-toward rate 0.78 (first 10) → 1.00 (last 10). Negative relief occurred
ONLY on exploratory wrong actions (e.g. trial 21 explore turn_left in far_right,
relief −0.156) — the punishment channel, visibly teaching. Final biases (all four
bins correct sign):

| bin | turn_left | turn_right | argmax |
|---|---|---|---|
| far_left | **+0.107** | −0.005 | turn_left ✓ |
| near_left | **+0.117** | −0.020 | turn_left ✓ |
| near_right | −0.092 | **+0.078** | turn_right ✓ |
| far_right | −0.040 | **+0.073** | turn_right ✓ |

Apparatus gain EMA ended 0.52/rad (sweep: 0.58 tracked). One-trial operant learning
was directly visible in s1 (trial 2 wrong-explore → negative relief → trial 3 greedy
flip to correct in the same bin).

### Arm 2 — cross-session transfer (s2, loaded NAc): **PASS**

`[probe 0] correctness=1.00` — all four bins argmax-correct on the loaded NAc
**before any trial of the session**. Full session (36 trials; ended at trial 36 by a
transient SDK motion-ack timeout, not a learning event — see note): **every probe
(0, 5, ..., 35) = 1.00; greedy turned-toward rate 1.00 overall** (31 greedy trials,
first-10 1.00, last-10 1.00, mean greedy relief +0.080); negative relief occurred on
exactly the 3 exploratory wrong actions and nowhere else; all four bins visited
(14/5/11/6). The loaded policy was correct from the first action and never wavered.
*Infra note:* the session terminated at trial 36/40 when `goto_target`'s
task-completion ack timed out once over Wi-Fi (SDK budget duration+1 s) — fixed with
an idempotent absolute-target retry in `LiveRig._goto` + checkpoint cadence 10→5;
scientifically immaterial (trials 1-36 + all probes are in the JSONL, checkpoint
converged).

### Arm 3 — merge / fleet mechanics (m1 + orient_merge_arm): **PASS**

**m1 (independent replication, fresh NAc, seed 42, 40 trials):** greedy turned-toward
rate **0.50 (first 10, literal chance) → 1.00 (last 10)**; probe trajectory 0.00 →
0.25 (5) → 0.50 (10) → **1.00 (15) → held through 40**; mean greedy relief +0.058;
all bins visited (13/5/11/11); the two greedy negative-relief events were mid-learning,
none after convergence. m1 doubles as a full replication of Arm 1 on a fresh substrate.

**Merge (`nac_merge(s2-NAc, m1-NAc)` + probe gauntlet):** left 1.00, right 1.00,
**merged 1.00** — every bin argmax-correct, merged biases the provenance-tagged means
of the inputs (e.g. near_left turn_left 0.242 + 0.092 → 0.167). Gauntlet **PASS**
(threshold 1.0 AND merged ≥ both inputs). Merged NAc persisted
(`nac_merged.json` — a robot bootstrapped from it starts probe-correct) and exported
as the first queen-mind bundle: `queen_mind_orient_v0_1.zip`, manifest
`{contributor_id: dennys-reachy-01, domain: robotics-orient, identity_filter_applied:
true, schema_version: 1, signature: null (reserved 1.1)}`.
Dry rehearsal had additionally shown the repair property: a weak input (0.75) merged
into a 1.00 policy — merged ≥ max(inputs) is not merely preserved, it can improve.

### Negative controls (offline, dry harness)

- Wrong sign flag: startup self-check aborts before learning with the corrective flag
  named; if forced past it, probe correctness pins at 0 with a fully reversed argmax
  table (distinct from "didn't learn" ≈ 0.5).
- Dry worlds in both yaw→az conventions converge to 1.00 with the matching flag.

## Interpretation

The policy is **learned, not engineered**: it starts at zero knowledge, converges within ~10
hardware trials, survives process restart via the persisted substrate, and merges
across independent learners into a policy at least as correct as either input. The LLM is absent from the action path;
the coach/prompt layers are absent entirely. This is the first real-hardware
substrate sensorimotor policy in the project — Layer 1 of the orient line, the rung
below spatial co-location grounding (Layer 2).

Honest limits: 1-D policy, 4 states × 2 actions (small by design — the claim is the
*pipeline*, not the task difficulty); state bins are literal strings, not EC nodes
(the az-region EC upgrade is the planned substrate-native step); front/back ambiguity
unaddressed (eared-shell follow-up, pre-registered); apparatus servo shares the turn
primitive with the learner (mitigated by event-tagged logging + the probe metric
being motion-free).
