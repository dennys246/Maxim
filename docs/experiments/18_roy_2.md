## What this proves

The headline finding from Roy-2 separates two questions Roy-1b's methodology refinement raised:

1. **Negative for the structural question (path (a) does NOT widen cluster vocabulary).** The cradle linguistic narration is consumed by the orchestrator narrator (LLM) but not directly by substrate-primary AUT's tool proposer — so the 50-turn cold-start regime keeps the `sense_food_source` monoculture regardless of arc choice. The cluster wire writes the same six +1.0 keys keyed to the same single tool. This rules out path (a) of Roy-1b's three-pointer refinement: widening priming arcs alone is not sufficient to break substrate-primary's cold-start tool monoculture. The cold-start gate is in the AUT proposer, not in the orchestrator's percept emission.

2. **Partial-positive for the behavioral question (A vs C tool distributions diverge).** The substrate-only A vs C contrast (both neutral prompts) shows arm A's test-phase tool distribution diverges from arm C — A uses `sense` + `pick_up` variants where C uses `look` + `listen`. The signal is mediated by the LLM proposer reading substrate context indirectly (through salience-modulated WMS, recalled hippocampal memories, or affordance hints surfaced in the prompt), **not** through the `cluster_reward_bias` path. This is the first behavioral signal in the Roy harness that survives the A-vs-blank-neutral contrast under llm-primary, though it's subtle and prompt-mediated rather than a clean substrate-drives-action divergence.

3. **First clean valence_KS reading in Roy harness history.** Roy-1a missed α=0.05 (p=0.402); Roy-1b cleared it but with single-episode blank arm (sample-driven artefact). Roy-2's **`valence_KS = 0.291 (p=0.023)`** with 26-episode blank arm and 685-episode primed arm gives the first methodologically-clean significant valence signal across iterations. The substrate priming wrote negative-mean valence (-0.09) onto arm A's episode distribution; held-out percepts on the blank arms fire neutral-mean episodes (0.0). This is the strongest cross-iteration evidence that substrate carryover propagates to the Hippocampus valence distribution.

4. **Salience_KS effect size shrinks as priming episode diversity grows.** Roy-1a's `salience_KS = 0.879 (p=2.1e-9)` reflects 665 cradle_prelinguistic episodes' novelty against held-out test percepts. Roy-2's `salience_KS = 0.529 (p=6.9e-15)` reflects 685 episodes split across 3 prelinguistic stages + 2 cradle stages — more diverse priming episodes shrink the novelty gap (the substrate has "seen more" so held-out percepts are relatively less novel). The p-value is still highly significant; the effect-size shrinkage is methodologically informative — diversity is a quantifiable knob on salience carryover.

### Definitively proved regardless of headline values

- **The cluster wire is rock-solid across iterations.** Roy-0 → Roy-1a → Roy-1b → Roy-2: `cluster_reward_bias_l2` within 1% (2.4587 → 2.4495 → 2.4678 → 2.4495). Four single-seed iterations reproduce the same priming-side wire output.
- **The held-out fixture is mode-agnostic AND arc-mix-agnostic.** 30/30 test turns clean across both AUT modes and across two priming arc configurations.
- **Multi-arc priming at the orchestrator level does NOT shift substrate-primary's cold-start AUT proposer.** The AUT-side tool monoculture is invariant under arc-mix changes in this turn budget.

## What this still does NOT prove

- **Behavioral expression via the `cluster_reward_bias` path.** Still zero `sense_food_source` calls at test time under llm-primary — the cluster bias remains structurally present and behaviorally inert through this path.
- **That Roy-2b (substrate-primary at test on the same priming) would exploit the cradle-stage associations.** The cradle stages may have produced richer causal links / ATL chunks (not visible in the cluster wire) that substrate-primary's `recommend_action` could read. Unmeasured.
- **`min_confidence` tuning impact.** Untested; would require Roy-2c.
- **Wire 1 sufficiency.** Untested.
- **Cross-session persistence.** Still single-session.
