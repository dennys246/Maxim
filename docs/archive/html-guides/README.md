# Legacy HTML guides — ARCHIVED 2026-08-26

The 31 standalone HTML guides that were the project's documentation before
[pymaxim.bio](https://pymaxim.bio) (canonical since 1.0.9 — see
`docs/publication_guide.md` §6: the legacy guides are "a migration source, not a second
authority"). Kept in the tree because 11 of them have no Markdown or site equivalent yet
(agent-architecture, memory-systems, semantic-memory, prompt-system, attention-salience,
math-cognition, sound-orientation, technical-deepdive, usage-guide, **privacy-policy**,
**terms-and-conditions**) and the README still publishes the hosted copies at
`dennyschaedig.com/maxim/*`. Nothing in `src/`, `tests/`, CI or the wheel references
this directory. Content is frozen as of 2026-06-17; do not update it — migrate a guide to
`docs/` or the site and then delete it here.
