# Legacy HTML guides — ARCHIVED, FROZEN

The 31 standalone HTML guides that were the project's documentation before
[pymaxim.bio](https://pymaxim.bio) became canonical (1.0.9; see
`docs/publication_guide.md` §6). **These are frozen copies** — content as of
2026-06-17, archived 2026-08-26. Do not update them; nothing in `src/`, `tests/`,
CI, or the wheel reads this directory. Fix the live page instead:

- **pymaxim.bio is canonical** for reference, guides, and evidence.
- **dennyschaedig.com/maxim** now hosts only the *design essays* (the "why");
  its retired reference pages redirect to pymaxim.bio.
