- **[engineering] `PerceptSource` and `ActionSink` are minimal protocols with no orchestrator, narrative-phase, conversational-turn, or tool-registry coupling** (CC8, v1.0 freeze, 2026-04-29). Required: `PerceptSource` exposes `name`, `next_percept()`, `is_exhausted()`, `capabilities`; `ActionSink` exposes `record(action)` + `actions`. Optional duck-typed extensions (`has_pending`, `advance_step`) are probed via `hasattr`/`getattr` with sensible defaults. New optional extensions follow the same duck-typed-with-default pattern. The `is_sim_mode` flag in [runtime/sim_adapter.py](src/maxim/runtime/sim_adapter.py) is more accurately read as "an external adapter is driving percepts" — kept as `is_sim_mode` for back-compat. Behaviors gated by the flag: skip Default Network startup, sim-specific `sim_log` calls, skip LLM fallback proposals, AND end the session via `MemoryHub.on_session_end_lightweight()` (skipping the blocking sleep/replay consolidation). The lightweight session-end is correct for short-lived sim runs but **may surprise long-running external adapters** (e.g. a Minecraft session running for hours expects full consolidation). The 1.0 trade-off is preserved to avoid changing existing sim behavior; revisit when the first non-sim adapter ships and decide whether to split the flag (`is_external_adapter` vs `is_sim_mode`) or wire `end_bio_session(is_sim_mode=False, ...)` per adapter. The `isinstance(percept_source, SimulationBridge)` checks in `resolve_confirmation` / `resolve_plan_approval` / `resolve_timeout_retry` are intentional orchestrator-coupled escape hatches — non-sim adapters fall through to the default `"yes"` / `None` and own confirmation resolution themselves. The previously-dead `getattr(percept_source, "_bridge", None)` fallback was removed in the CC8 fold round (no producer ever wired it). Regression guard: [src/maxim/simulation/sources.py](src/maxim/simulation/sources.py) (`PerceptSource` Protocol shape) + [src/maxim/runtime/sim_adapter.py](src/maxim/runtime/sim_adapter.py) (`is_sim_mode` flag site).
