**[engineering] TTFT keepalive emitter writes to `self.wfile` under a lock shared with the main chunk writer** (llm_timeout_scalability.md Stage 3, 2026-06-03). When the leader proxy forwards a streaming LLM response (Content-Type `text/event-stream`) through cloudflared, the tunnel's ~100s idle timeout closes the connection if no bytes flow during the upstream's time-to-first-token window. For 30B+ models on edge hardware (Mac Mini, Jetson, etc.) TTFT can routinely exceed 100s and the proxy doesn't notice until it tries to write the first real chunk and gets EPIPE — symptom is `chunks=1 elapsed_ms=149+` in the proxy log. `runtime/leader_proxy.py::_run_keepalive_emitter` runs in a daemon thread alongside the main `_proxy_request` chunk loop, writing `_KEEPALIVE_CHUNK_FRAME` (an HTTP/1.1 chunked frame carrying `: keepalive\n\n` — valid SSE comment per spec, clients ignore) every `MAXIM_PROXY_KEEPALIVE_INTERVAL_S` (default 30, clamped 5-90). Both the emitter and the main chunk writer target `self.wfile` (a single socket); **concurrent writes without synchronisation interleave bytes mid-frame and corrupt the chunked encoding**, so the emitter MUST acquire `write_lock` (a `threading.Lock` declared at the same scope as `stream` so the `finally` block can stop the emitter on every exit path) around each write. The emitter exits on (a) `stop_event.set()` from the main thread on first real chunk, (b) any write exception (treated as client disconnect — sets the stop event for symmetric cleanup), (c) the `finally` block setting the event during error paths. Only fires when `_is_event_stream_response(resp_headers)` returns True — buffered (`application/json`) responses have no in-band slot for SSE comment frames and would be corrupted by injection. The `stop_event.set()` happens BEFORE acquiring `write_lock` in the chunk loop so the emitter sees the signal during its next `wait()` wakeup; reversing the order would let the emitter park at `with write_lock` and emit one extra keepalive AFTER the first real chunk. Regression guard: [tests/unit/test_leader_proxy.py](tests/unit/test_leader_proxy.py) — `TestKeepaliveChunkFrameFormat` pins the wire format, `TestKeepaliveEmitter` pins emit cadence + stop semantics + write-error handling + lock release.
