- **[engineering] `TemporalCreditDistributor.record_event` is the canonical intake for EVERY temporally-anchored event — do NOT build an "SCN bus"** (2026-07-29 audit). One call fans out to all three consumers: `nac.update_eligibility()` (fast-decay trace), `scn.register()` (bin indexing), `scn.observe_event()` (oscillator per-event-type circadian phase). A new consumer belongs INSIDE `record_event`, not behind a new pub/sub layer. The front-gate question was run explicitly and the answer is ride-on-existing: the centralized intake already exists, a bus would not fix the actual failure (a producer that forgets `record_event` forgets `bus.publish` identically), and this codebase already carries four buses (`PainBus`, `ReactionBus`, `AgentBus`, `LocalMessageBus`) plus a deferred *Unified* Event Bus — a fifth single-purpose bus moves the wrong way. **The real failure mode is silent non-arrival**, and it has already been missed repeatedly: of the six `event_type` categories `TemporalEvent` declares, only `tool` has a producer; the `Embodiment` drive emitter is unwired AND its constructor call is malformed, failing into a bare `except Exception: log.debug(...)`. When adding a temporal-event producer: construct via the required fields (`event_id`, `event_type`, `event_signature`, `agent_id`, `temporal_sig` — note `temporal_sig`/`context`, NOT `temporal_signature`/`metadata`), pass the distributor explicitly, and do NOT wrap the emit in a bare `except Exception` — a swallowed `TypeError` is exactly how the drive path stayed dead unnoticed. Per the push-silent-no-ops-into-types rule, an emitter's `distributor` should be required keyword-only with `None` as the explicit opt-out. Gap inventory + the recommended structural fix: [docs/plans/deferred/scn_event_producer_gap.md](docs/plans/deferred/scn_event_producer_gap.md). Regression guard: none yet — this documents an ABSENCE by design (missing-is-the-signal); `scripts/check_oscillator_coldstart.py` reports `drive=0` with a pointer to the plan, and the "every declared category has a producer or is marked reserved" test is the tracked follow-up that would make it enforceable.
