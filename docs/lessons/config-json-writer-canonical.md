- **[engineering] `~/.config/maxim/config.json` is the operator-config layer; `runtime/config_writer.py` is the canonical writer site** (config_unification.md C1+C2, 2026-06-02, PR pending). Maxim's CLI-canonical instance config absorbs ~22 daily-use `MAXIM_*` env vars onto one source of truth. Path mirrors `peer.yml` / `mesh.yml` / `profiles.yml`. Precedence chain (CLI > env > config.json > builtin defaults) is exposed via `maxim.runtime.config_loader.resolve_setting(field_path, cli_value=None, *, config=cfg)`. Override logging is load-bearing: shadow (env mismatches config) logs WARNING; convergence (env and config agree) logs INFO (the Mac Mini "two sources of truth set, operator doesn't know which wins" failure class). Empty-string env vars are treated as UNSET via `_env_is_set` per the pre-implementation C-1 fold (the leaked-`export FOO=` Mac Mini Trigger #4). The deprecation INFO for absorbed env vars fires exactly once per env var per startup via a module-level `_warned_envs` set. **`runtime/config_writer.py` is the only sanctioned writer for config.json** — `write_config` / `mutate_config` / `set_field` use `atomic_write_json` + `with_format_version` (the canonical CC1 helper per the post-implementation Architecture #1 fold) under a `filelock.FileLock` that acquires BEFORE the read (the pre-implementation I-5 concurrent-set fold). The mesh.yml two-layer-split invariant applies: declarative config files are operator-explicit one-shot setup verbs only — no automatic runtime / admin-API writes. CI grep allow-list enforces single-writer (see Regression guard below). API key references (`lanes.<tier>.remote_api_key_ref`) accept ONLY file paths (`/...` or `~/...`) or keyring URIs (`keyring:<service>:<account>`). Inline plaintext keys are rejected at load time per the cross-confirmed pre-implementation I-3/IM3 fold; the legacy `MAXIM_LANE_<TIER>_REMOTE_API_KEY` env-var path still passes inline keys through (legacy semantics). Regression guard: CI grep in [.github/workflows/test.yml](.github/workflows/test.yml) ("config_unification.md C2 + C6 invariants (IM2 fold)") allow-lists callers of `write_config` / `mutate_config` / `set_field` — new callers fail CI; tests in [tests/unit/test_config_writer.py](tests/unit/test_config_writer.py) + [tests/unit/test_config_cli.py](tests/unit/test_config_cli.py) + [tests/unit/test_config_loader.py](tests/unit/test_config_loader.py) pin every fold from the pre-implementation review.
