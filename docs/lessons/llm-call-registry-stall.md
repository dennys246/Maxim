- **[engineering] `runtime/llm_call_registry.py` is the canonical in-flight LLM call surface; `runtime/stall_threshold.py::compute_stall_threshold` is the canonical stall-threshold derivation** (stall_detector_timeout_awareness.md, 2026-06-04). New stall detectors MUST consult `compute_stall_threshold(*, lane_tier, lane_timeout_s, ...)` rather than defining their own hardcoded thresholds. The orchestrator stall detector + heartbeat monitor (Stage 2, pending; allowlisted in CI grep until then) + `maxim doctor`'s Derived Config rows all query `any_call_in_flight(tier=...)` + `oldest_byte_silence_s(tier=...)` from the registry to suppress nudges during legitimate inference. The instrumentation site is **`models/language/router.py::LLMRouter._complete_text_locked`** (one `register_call_start` at dispatch entry, one `register_call_end` in `try/finally` covering the provider-fallback loop) — wrapping at the per-backend `complete_with_usage` layer is **incorrect** because it leaves a gap between provider-A end and provider-B start where the orchestrator's stall detector would fire spurious nudges mid-failover. Byte-arrival updates flow from per-backend `_stream_response` chunk loops via `register_byte_received()` reading the active call_id from a ContextVar (no signature threading needed); this includes PR #320 TTFT keepalive frames (`: keepalive\n\n`) which the SSE parser sees as bytes-on-wire. `register_call_start` / `register_call_end` use **stack-token LIFO semantics** so nested dispatches don't strand the outer call's ContextVar. The `_InFlightCall` dataclass is SHAPE-FROZEN at 1.0 (CC3) with an `extra: dict` escape hatch rejected because the registry's value type has no caller-extensible metadata; `compute_stall_threshold` accepts `model`/`prompt_tokens`/`**future` kwargs as forward-compat for `llm_timeout_scalability.md` Stage 4 adaptive prediction (1.1). **Known limitation:** the orchestrator's `_stall_detector` hardcodes `lane_tier="large"` and reads `MAXIM_LANE_LARGE_TIMEOUT_S` directly (not via `LaneConfig.remote_timeout_s`) — this drifts silently if an operator configures `lanes.large.timeout_s` via `config.json` only without env-var bridge; tracked as a follow-up for the FunctionRouter-consultation migration. Regression guard: [tests/unit/test_llm_call_registry.py](tests/unit/test_llm_call_registry.py) (15 tests incl. LIFO + nested-dispatch) + [tests/unit/test_stall_threshold.py](tests/unit/test_stall_threshold.py) (20 tests) + [tests/unit/test_stall_detector_with_registry.py](tests/unit/test_stall_detector_with_registry.py) (6 integration tests) + CI grep in [.github/workflows/test.yml](.github/workflows/test.yml) blocking hardcoded `STALL_S=30` assignment literals outside the canonical module (heartbeat.py allowlisted pending Stage 2; pattern is assignment-only — arithmetic expressions and non-`STALL`-prefixed identifiers are intentionally not enforced).
