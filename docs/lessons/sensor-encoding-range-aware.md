- **[engineering] Signed (`[-1,1]`) sensors MUST be encoded WITH their range through `SensorEncoder`, or they FOLD** (P1, 2026-07-20). `similarity/encoder.py::_normalize_value(value, value_range=None)` maps a sensor value into `[0,1]` for the low/high basis interpolation. WITHOUT a range it uses a range-BLIND bimodal map that FOLDS a signed sensor — center `0.0` aliases hard-left `-1.0`, and opposite-signed values collide near center (`-0.5` and `+0.25` both → `0.25`) — so left vs right azimuth can share one EC cluster and a direction-conditioned policy (orient) can't separate them. WITH a range it maps linearly `(v-lo)/(hi-lo)` (monotonic; `[0,1]` is the identity). The no-range path is kept **byte-identical to pre-P1** (fuzz-verified over 200k values) so every legacy caller is unchanged; a caller needing a signed sensor's SIGN preserved MUST thread `ranges={name:(lo,hi)}` through `encode_sensors` / `_sensor_embed`. The production substrate-primary path does this via `runtime/agent_loop.py::_read_drive_ranges`, which walks `drive_specs` **parallel to `_read_drive_states`** — the two walks MUST emit the same drive set (a signed drive with a value but no range silently re-folds), and `_read_drive_ranges` guards each `float(range)` **per-sensor** (a malformed YAML range must NOT raise: it is evaluated inside the `encode_sensors` try/except, so a raise would silently disable ALL substrate encoding for the agent, every tick — skip the bad sensor to the legacy map instead). **UNITS:** `reading_schema["range"]` must be in the same units as the values in `vital_metrics` (they are — `spec.py` inits `vital_metrics` from the declared range); a raw-unit range (`[0,360]`) with normalized values would map everything near `0` (worse than the fold). Interaction with the EC centroid-drift lesson is **strictly safer** — under a frozen-centroid modality, monotonic encoding produces MORE pattern-separation into distinct frozen prototypes, not the running-mean collapse folding risked. Behaviorally: the fold fix takes the orient full-path probe full-range `0.847 → 1.000` and does NOT regress Exp 42 (GRADUATE, `git_hash`-verified `4149eed0`). Regression guard: [tests/unit/test_normalize_value_range_aware.py](tests/unit/test_normalize_value_range_aware.py) (byte-identical legacy incl. the fold, monotonic range-aware, `[0,1]` identity, left/right separation, the two-walk drift guard on real reachy+infant bodies, malformed-range skip) + [scripts/orient_substrate/2_full_path_probe.py](scripts/orient_substrate/2_full_path_probe.py).
