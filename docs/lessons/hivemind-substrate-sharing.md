- **[engineering] `src/maxim/hivemind/` is the substrate-sharing layer** (v1 §B5 Hivemind shareability, 2026-05-30 / 2026-05-31, PRs #305/#308/#309/#310). The four-PR surface is the load-bearing contract that the gated 1.2 Oasis ingestion and P2P Hivemind protocol depend on; later work builds ON these surfaces without retrofitting them. (Roadmap timing moved from 1.1/1.2 to gated 1.2 on 2026-08-19; the shipped contract is unchanged.)
  - **`hivemind/merge.py` provides `nac_merge` / `ec_merge`** as pure-function utilities consuming `NAc.dump()`-shape state dicts and the `substrate_nodes` slice of `EC.save()`. Inputs are never mutated; outputs are fresh dicts that load cleanly via `NAc.load_state` / `EC.load`. **Both functions REQUIRE keyword-only `left_source=` / `right_source=`** and route them through `_validate_source` which rejects (a) non-strings + empty strings and (b) any contributor ID in the reserved `_*` namespace. The validator is the shared entry point — `hivemind/bundle.py::compose_bundle` reuses it for `contributor_id` validation rather than re-implementing the check. Adding a third entry point that takes a `source`/contributor ID MUST also route through `_validate_source`.
  - **Reserved-namespace registry**: `_consensus` (`merge.CONSENSUS_SOURCE`) marks a link/node aggregated across ≥2 contributors; `_identity` (`identity.IDENTITY_DOMAIN_MARKER`) marks an EC node the operator wants quarantined from every bundle regardless of any other domain filter. New `_*`-prefixed sentinels must be documented in the module that introduces them AND rejected by `_validate_source` (which catches the entire prefix uniformly). Do NOT use `_*` for non-sentinel internal state — the prefix is a public-facing reservation.
  - **`ec_merge` respects `frozen_centroid_modalities`** (PR D bio-fidelity fold). When the matched node's modality is in `frozen_centroid_modalities` (default: `DEFAULT_FROZEN_CENTROID_MODALITIES`, which MUST equal `ECConfig.frozen_centroid_modalities` — `{"interoception", "audio"}` as of 2026-08-06. The two are duplicated literals because the hivemind layer deliberately avoids internal-module imports, so `test_hivemind_frozen_modalities_match_ec_default` pins the equality. They HAD silently diverged: `"audio"` was added to `ECConfig` in PR #383 and never mirrored here, so a default-argument `ec_merge` running-mean-updated audio centroids across contributors — exactly the drift the frozen contract prevents — on the modality Exp 45/48 rest on), the merge accumulates `count` + `contributors` but does NOT update the centroid embedding. This preserves the bio-fidelity invariant from the EC centroid-drift lesson: a running-mean centroid update across contributors would re-introduce the drift the frozen-modality contract was designed to prevent within a single substrate. Callers MUST NOT bypass the parameter — adding a new caller that wants a different frozen set passes it explicitly; do NOT mutate the default.
  - **`hivemind/identity.py` is a substrate-only heuristic**, NOT the full Mother-plan ATL/SEM identity-map walk (deferred to 1.1+ via the documented `identity_map: set[str]` parameter slot). Bundle-default threshold is `2` (vs the heuristic's default of `1`) because PR C's architecture review flagged game-substrate over-flagging at threshold=1; this asymmetry is intentional. The English-skew + bio-system-context-unused limitations are documented in the module docstring.
  - **`hivemind/bundle.py` ships substrate snapshot bundles as a ZIP** of `manifest.json` + `nac.json` + `ec.json`. Hippocampus episodes are NEVER included by construction — the load-bearing privacy invariant from [maxim_hivemind.md](docs/plans/maxim_hivemind.md). **The `nac.json` slice is additionally content-scrubbed at composition, UNCONDITIONALLY** (PR #506): `scrub_nac_state_for_bundle` allowlists `event_context` to `agent_id`, replaces `outcome_signature` with the canonical merge-safe `{outcome_type}:{valence}` form (free-text outcome summaries carried raw tool output/paths/credentials; the canonical form preserves `nac_merge`'s by-outcome pairing + valence-separation preconditions — a first-token truncation was refuted in the pre-merge round for silently clobbering links on merge), empties `memory_ids`/`percept_refs`, drops `goal_reward_bias` (keys are verbatim user/LLM goal text) + `priors`, truncates non-identifier `tool:use:<action>` signature tails across all four signature surfaces with proper collision merging (`_merge_link_pair`/parallel-Welford/mean/`mixed`), gates `percept_valences` entity classes to identifier-shaped tokens, and rebuilds `outcome_index` from the shipped links. The identity filter additionally covers `event_outcome_welford` keys. Scrub-at-composition, never at capture — local state stays fully populated for debugging. Regression guard: [tests/unit/test_hivemind_bundle.py](tests/unit/test_hivemind_bundle.py) (sentinel tests per field + scrub→`nac_merge` round-trip + AST guard pinning the scrubber inline in the `nac.json` serialization, verified to fail on the pre-fix shape). ATL, reflexes, and cerebellum payloads are reserved for 1.1 (the migration-registry seam is in place: bumping `BUNDLE_SCHEMA_VERSION` to 2 + registering a v1 migration via `register_bundle_migration` is the only change needed). Every ZIP entry is routed through `_safe_join` which rejects empty names, absolute paths, and any resolved target outside `output_dir` (ZIP-slip CVE class). Manifest `signature` + `signature_algorithm` slots are reserved-null at 1.0; populating them is 1.1+ verification work. **Manifests additionally carry `encoder_provenance` (1.1 item 7, artifact stamping):** `observed_embedding_dims` is DERIVED per-modality from the actual arrays in the shipped EC slice at write time (never declared), and `recorded` passes through the source `ec.json`'s encode-time stamps verbatim EXCEPT path-shaped strings, which compose-time redacts to `[REDACTED_PATH]` (PR #506 — a local-checkpoint `model_name` must not ship; consequence for 1.2: per-contributor provenance union cannot decide same-local-checkpoint equality across bundles once both stamps read the marker) — `None` for pre-stamping payloads (honest unknown, never fabricated; the CLI reads it from the payload, NEVER from its own encoder singleton, which need not match the writer's). `recorded` describes THIS bundle's composing substrate only — nodes previously imported via `ec_merge` may carry foreign calibration not reflected in it; the 1.2 P2P merge must union provenance per-contributor rather than trusting a merged substrate's local stamps. Additive manifest keys at `schema_version` 1 follow the `signer_identity` precedent (optional, read via `.get`); new SLICES still require the schema bump + migration. Encoders stamp via `EC.record_encoder_provenance` at ENCODE time (direct typed call — a silent-no-op probe here would ship stamp-less state, the exact leak the stamp prevents). Regression guard: [tests/unit/test_artifact_stamping.py](tests/unit/test_artifact_stamping.py) (16 tests incl. the CLI read-from-payload seam + old-file compat both directions).
  - **`hivemind/cli.py::run_substrate_subcommand` is dispatched from `maxim/cli.py`** for the `substrate` positional subcommand. The 1.0 `import` verb extracts only — it does NOT auto-merge into a live system; managed live ingestion is reserved for the gated 1.2 Oasis pipeline so PR D stays side-effect-free at the bio-stack layer.
  - **1.2 poison-resistance hooks** ride on `trusted_sources: frozenset[str] | None` + `validate_link` / `validate_node: Callable | None` keyword-only parameters on both merge functions. They default `None` (no filter) at 1.0; 1.2 wires actual callers. Adding new merge entry points MUST reserve the same parameter shape so the 1.2 P2P protocol doesn't need to retrofit.
  - Regression guard: [tests/unit/test_hivemind_merge.py](tests/unit/test_hivemind_merge.py) (Welford parallel-merge correctness, valence-distinct-stays-separate, sorted-key determinism, frozen-modality preservation, reserved-namespace rejection) + [tests/unit/test_hivemind_identity.py](tests/unit/test_hivemind_identity.py) (short-proper-noun coverage, threshold semantics) + [tests/unit/test_hivemind_bundle.py](tests/unit/test_hivemind_bundle.py) (ZIP-slip rejection, migration-seam, float-precision survival, identity filter, end-to-end round-trip through real NAc + EC instances).
