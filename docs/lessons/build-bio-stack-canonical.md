- **[engineering] `runtime/bio_stack.py::build_bio_stack` is the canonical bio-pipeline construction site** (Wave 3 of biosystem_unification, 2026-04-17). Composes the four individual Wave 1+2 builders (`build_reaction_bus`, `build_pain_bus`, `build_memory_hub`, `build_default_network`) in the correct dependency order. Returns a frozen `BioStack` dataclass containing all wired bio-systems. `persistence_dir: Path | str | None` is the primary configuration — sub-paths (`hippocampus.json`, `atl.json`, `angular_gyrus.json`) are derived internally. `pain_bus=` parameter accepts a pre-built PainBus (sim AUT pattern where the sandbox needs the bus before the rest of the stack); standard learners are subscribed to the pre-existing bus. `with_default_network=True` constructs a DefaultNetwork (Reachy + sim AUT only). **`agent_id=` is REQUIRED keyword-only** (2026-05-27 fold of exp 32 Bug A): the prior `default_agent` default produced a silent agent_id divergence between `MemoryHub.agent_id` and every other agent_id surface, breaking Wire-A's cross-session annotation read. Same silent-no-op pattern as `build_executor(pain_bus=...)` and `build_pain_bus(hippocampus=..., nac=...)` — pushed into the type so the next miss is a `TypeError`, not a silent agent_id divergence. **Two production callers** (the AgentFactory consolidation finished after this invariant's initial write): `AgentFactory.create_full_agent` — which itself fans out to CLI non-sim, simulation/orchestrator.py AUT + orch NPC, and headless `pymaxim` — and `embodied_runtime/agentic_runtime.py` Reachy. CLI sim modes stay as-is (just `build_pain_bus`). `build_memory_hub` carries the same required-`agent_id=` contract. See [docs/plans/archive/bio_stack_unification.md](docs/plans/archive/bio_stack_unification.md).
