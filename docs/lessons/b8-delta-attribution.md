- **[engineering] Drive-spec embodiment failures are delta-attributed: a tool is blamed only for breaches its OWN effect caused** (B8, Exp 42, 2026-06-23). `ModulatorAffordanceTool.execute` filters the `FailureEvent`s it reports into `side_effects["embodiment_failures"]`: a **drive-spec** failure (name `drive:<sensor>:discomfort` / `:deprived`, parsed by `_drive_failure_sensor`) is included only when the affordance's own `self_effect`/`target_effect` delta is *intrinsically harmful* to that sensor — i.e. that delta alone would breach a healthy sensor (`_intrinsically_harmful_sensors`: homeostatic `|delta| > comfort_band`; entropic delta past `deprivation_threshold` in the deprivation direction). **Standard (non-drive) `failure_mode`s pass through unchanged**, so the SEM pain cascade + Exp 37/38 are preserved (the *causing* tool still reports; only a *bystander* affordance executing while another tool's breach lingers is spared — the mis-attribution that collapsed Exp 42's safe-vs-harm discrimination). **On any filter error, fall back to the UNFILTERED events** (pre-B8 behavior), never to empty — a filter bug must not silently drop the causing tool's failure. **SCOPE (updated 2026-07-28):** this filters the `side_effects`/direct-attribution channel ONLY; the parallel PainBus channel is severity-latched at the source instead (see the transition-based drive-pain invariant below). **B8 is NOT redundant and must NOT be removed** — the pre-merge two-lens round proved the opposite of the original plan's Phase-3 guess: because `_intrinsically_harmful_sensors` keys on the affordance's own delta and NOT on sensor state, it is the only mechanism that still separates causer from bystander when a sensor **saturates** (`arms.thermal` clamps at 1.0, where a severity latch can detect no further deepening). An earlier draft of this fold latched the direct channel too; both review lenses independently reproduced the consequence — the repeat harmful affordance emitted no `embodiment_failures`, so `learn_success` flipped True and the collateral-harm gate went silent, booking **positive** cluster reward for the harmful hearth and collapsing Exp 42's safe-vs-harm discrimination. Regression guard for that specific inversion: [tests/unit/test_substrate_primary_scene_harm.py::test_execute_delta_attribution_causing_vs_bystander_on_chilled_body](tests/unit/test_substrate_primary_scene_harm.py) (repeat-causer arm; verified to fail on the latched-direct-channel design). B8 is the mechanism that earned the Exp 42 #6 GRADUATE (the B7 drive-gating arm proved redundant in the ablation and is Dormant).
