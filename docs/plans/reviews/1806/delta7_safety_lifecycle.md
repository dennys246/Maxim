**Out of scope, recorded for the owner (not new in v8, no fold owed here):**
- **Reconnect does not re-check liveness.** `media_required` is per-call and is never inherited by `reconnect()`/`_soft_reconnect` (delta-5 N2, deliberate). So a `media_required` run whose camera comes back dead after a soft reconnect continues blind. The strict-perception guarantee holds at **connect time only**. Worth one residual sentence in §3a. Same class as E5/G1, no motion.
- **Unpinned networked entries are not covered by the allowlist.** It is scoped to pinned entries. An unpinned networked entry with an explicit `media_backend: local` still reads the Maxim host's camera. That is today's behaviour, it is labelled UNPINNED, and it lies on the unchanged stable surface (§3c), so it is outside H2. Extending the allowlist to every non-proven entry would cost one word ("an entry", not "a pinned entry"), if the owner wants it.

## Evidence

1. **`get_frame`** (`media/media_manager.py::MediaManager.get_frame`). `if self.camera is None: warning; return None`, else `return self.camera.read()`. There is no lock and no wait beyond `read()`.
2. **The bound** (`media/gstreamer_utils.py::get_sample`). `appsink.try_pull_sample(20_000_000)` returns `None` on timeout. Both `camera_gstreamer.py::GStreamerCamera.read` and `webrtc_client_gstreamer.py::GstWebRTCClient.read` return `None` when `get_sample` does, and otherwise `np.frombuffer(...).reshape((h, w, 3))`, which can raise (N7-2).
3. **Appsink queues.** `camera_gstreamer.py` and `webrtc_client_gstreamer.py` both set the video appsink to `drop=True`, `max-buffers=1` ("keep last image only"), so the queue never fills and a pull costs nothing a later reader needs.
4. **LOCAL `open()`** waits up to 2 s on `try-pull-sample` (100 ms each), inside `try/except Exception: pass`, and discards the result (N7-1). WEBRTC `open()` only sets PLAYING.
5. **No concurrent consumer at poll time** (`controller.py::connect` @ b7380ee7). `ReachyVideoStream(self._mini, ...)` is constructed after `ReachyMini(` returns and before `CONNECTED`. The runtime readers (`hardware/reachy/streams.py::_get_frame_internal`, `runtime/capture.py`, `embodied_runtime/media_loop.py`, `workers.py`, `selfy.py`) all reach `mini.media.get_frame()` only after a connected controller exists. `connect` does not hold `_motion_lock`, so the poll blocks no motion path.
6. **Backend resolution** (`reachy_mini.py::_configure_mediamanager`; `media/media_manager.py::MediaBackend`, `_DEPRECATED_BACKENDS`). `no_media` → NO_MEDIA. `default`/`auto` → LOCAL only under `connection_mode == "localhost_only"` with a local IPC endpoint, else WEBRTC. Any other string goes through `MediaBackend(s.lower())`, where `local` and `DEFAULT` give LOCAL directly and the four deprecated values map to LOCAL. Unknown strings fall back to auto-detect. A positive allowlist over `{default, auto, webrtc, no_media}`, together with the forced network mode for an unproven entry, therefore admits no LOCAL route (H2).
